## Day 17 Review

Today I practiced Python fundamentals, LeetCode, and SQL.

Python concepts:
- range(len(nums)) generates all valid indexes.
- nums[i] gets the value at index i.
- len(nums) returns the number of items in a list.
- nums[len(nums) - 1] gets the last value.
- list slicing such as nums[:write_pos + 1] returns part of a list.

LeetCode:
- Practiced Remove Duplicates from Sorted Array.
- Simple version uses a new result list.
- In-place version modifies the original nums list directly.
- write_pos means the position where the next unique number should be written.

SQL:
- WHERE filters original rows.
- GROUP BY groups rows.
- HAVING filters grouped results.
- ORDER BY sorts final results.
- LIMIT restricts the number of rows returned.
- COUNT counts rows.
- SUM calculates total amount.
- AVG calculates average amount.
- MAX finds the highest amount.
